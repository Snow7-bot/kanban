# 首页左侧导航宽度统一设计

## 目标

将首页专用左侧导航的宽度与 AI 问诊、病历记录共用的应用侧栏保持一致，把节省的水平空间全部让给首页中间内容区。

## 已确认尺寸

- 标准桌面：左侧导航宽度 `224px`，首页内容容器左偏移同步为 `224px`。
- 窄桌面（视口宽度不超过 `1100px`）：左侧导航宽度 `198px`，首页内容容器左偏移同步为 `198px`。
- 移动端（视口宽度不超过 `820px`）：左侧导航移出屏幕并通过菜单按钮打开，首页内容容器左偏移归零。

## 视觉调整

- 右侧个人资料、用药提醒和近期报告竖栏保持现有宽度与布局。
- 首页品牌区域、导航项和底部用户卡的水平间距适度收紧，避免在 `198px` 宽度下文字或头像拥挤。
- 不修改首页导航文案、图标、交互和颜色。

## 实现范围

- 仅修改首页样式及其布局回归测试。
- 不修改 AI 问诊、病历记录或共用 `Sidebar` 组件。
- 不进行无关重构。

## 验收标准

1. 标准桌面下首页左侧导航实际宽度为 `224px`，内容从 `x = 224px` 开始。
2. `1100px` 视口下首页左侧导航实际宽度为 `198px`，内容从 `x = 198px` 开始。
3. `820px` 及以下沿用移动端抽屉行为。
4. 导航文字、品牌和底部用户卡无截断、重叠或溢出。
5. 右侧竖栏宽度不变，自动化测试和生产构建通过。
