# Stitch 账户页面与统一左侧栏设计

## 目标

将家庭成员、个人资料和设置三张最新 Stitch 桌面原型接入现有康伴 React 应用，并让所有路由使用同一套左侧栏。

## 已确认约束

- 视觉基准：`stitch/PRD-Based-UI-Prototypes` 内三张参考图和 HTML。
- 侧栏：桌面端始终显示、移动端折叠为抽屉；所有现有及新增页面复用同一组件与相同导航顺序。
- 导航：保留已实现的首页、健康趋势、病历管理、AI 问诊、用药管理；新增家庭成员、个人资料、设置入口。首页、个人资料、家庭成员、健康趋势、病历管理的顺序沿用最新 Stitch 左栏，AI 问诊、用药管理、设置紧随其后，确保 PRD 已有模块均可到达。
- 组件：沿用项目的 `AppShell`、`Sidebar`、`TopBar`、`Card`、`Button` 和 token；不引入后端或新增依赖。
- 交互：导航可切换；家庭成员可选中成员并显示新增成员卡；个人资料表单可编辑并显示保存反馈；设置的老年模式、清除缓存和政策行提供本地可见反馈。

## 页面结构

### 家庭成员

标题、添加成员按钮、三张成员健康卡、添加卡与底部深色家庭健康概览。使用已拉取的本地头像资源；成员卡选中态与新增按钮均有反馈。

### 个人资料

身份信息卡、核心资料表单、联系方式区域、保存动作及通知/隐私入口。布局采用原型的白色卡片与红色主操作。

### 设置

与其他页面相同的应用左栏和既有顶部工具栏；内容保留原型的辅助功能、存储与数据、隐私与法律三块。设置页原图的顶部导航不再单独保留，避免与已确认的统一左栏重复。

## 验收

- `#family`、`#profile`、`#settings` 可直接访问并在统一侧栏中高亮。
- 3 个页面以下载的 Stitch 参考图为布局、色彩、间距和层级依据。
- 所有新导航路径被自动化测试覆盖；生产构建通过。
- 浏览器检查桌面和 390px 宽度下的导航、表单/开关和主按钮，且无横向溢出或控制台错误。
