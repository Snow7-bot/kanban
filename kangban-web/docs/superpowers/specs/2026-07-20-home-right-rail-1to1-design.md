# 首页右侧竖栏一比一复刻规格

日期：2026-07-20

## 目标与唯一参考

以用户提供的 `codex-clipboard-3032d8f3-891f-4294-bf74-317b360ea184.png` 为首页桌面端唯一视觉验收基准。参考图尺寸为 1330 × 1146。Stitch 编辑器的灰色提示浮层和页面外侧蓝色选中边框不属于产品页面，不复刻。

## 桌面布局

首页必须保持三栏结构，不允许右侧信息区横向铺到主内容下方：

1. 左侧导航栏固定在页面左侧，参考宽度约 288px，贯穿页面高度。
2. 中间主画布位于约 x=288–945，内容主体左边缘约 x=328、右边缘约 x=920，宽约 592px。
3. 右侧竖栏位于约 x=945–1320，栏内内容左右留白约 40px，卡片宽约 286px。

中间主画布继续包含问候区、AI 智能问诊卡和 2 × 2 健康指标卡。AI 卡参考位置约为 x=328、y=190、w=592、h=222；健康指标卡参考宽度约 283px，横向间距约 25px。

## 右侧竖栏

右栏中的内容按以下顺序单列向下排列：

1. 个人信息卡：顶部约 40px，宽约 286px，高约 260px。
2. 用药提醒：标题在个人信息卡下方约 38px；两张提醒卡均为单列，宽约 286px、高约 84px，卡间距约 14px。
3. 近期报告：标题在第二张提醒卡下方约 38px；报告卡宽约 286px、高约 158px。

右栏内部不得使用 `repeat(3, ...)` 或其他三列网格。桌面端任何适用断点都必须保持个人信息、用药提醒、近期报告纵向排列。

## 响应式规则

- 参考桌面视口及可容纳三栏的宽度：保持左侧导航、中间画布、右侧 360px 左右竖栏并排。
- 宽度不足以可靠容纳三栏时：进入现有移动布局，隐藏固定侧栏并显示移动顶部栏；右侧信息区放到主内容后方，但仍保持单列纵向排列。
- 禁止出现介于桌面与移动端之间的“三个右栏区块横排”状态。
- 390 × 844 下不得产生横向滚动。

## 变更范围

仅修改首页布局和响应式样式；不改健康趋势、AI 问诊、病历管理、用药管理页面，不改首页业务数据与导航逻辑。

## 验收

1. 增加回归测试，确保首页右栏不再存在三列横排规则。
2. 在 1330 × 1146 下截图，与参考图并排检查三栏分界、AI 卡、指标卡和右栏各卡片位置。
3. 在触发旧问题的中间宽度检查右栏仍为竖排。
4. 在 390 × 844 下检查无横向溢出。
5. 运行 `npm test` 和 `npm run build`。
