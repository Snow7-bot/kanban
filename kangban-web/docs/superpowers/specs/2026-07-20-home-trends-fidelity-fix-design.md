# 首页与健康趋势高保真修正设计

## 目标

严格依据本地 Stitch 原型重构首页与健康趋势页面，使页面壳层、版式比例、区块顺序、间距、色彩、字体层级、卡片尺寸和主要交互与参考截图一致。

## 视觉基准

- 首页截图：`stitch-prd-ui-prototypes/screens/05-home-redesigned.png`
- 首页原始代码：`stitch-prd-ui-prototypes/screens/05-home-redesigned.html`
- 健康趋势截图：`stitch-prd-ui-prototypes/screens/02-health-trends.png`
- 健康趋势原始代码：`stitch-prd-ui-prototypes/screens/02-health-trends.html`
- 设计系统：`stitch-prd-ui-prototypes/DESIGN.md`

参考截图是从 Stitch 原始画布等比缩放得到，验收时使用原始元数据视口：首页 2560×2224，健康趋势 2560×2416，再缩放至本地截图尺寸比较。

## 根因

当前实现把首页和健康趋势统一包裹在同一个 `AppShell` 左侧栏与顶部工具栏中，而 Stitch 原型使用两种不同页面壳层：

- 首页：280px 固定侧栏、主内容区、360px 右侧栏。
- 健康趋势：顶部横向导航、居中最大宽度内容区、12 栏主网格、底部页脚，无左侧栏。

因此当前差异是结构性差异，不能通过少量间距微调解决。

## 首页结构

- 固定 280px 左侧栏，品牌区、五个导航项、底部用户卡。
- 中间内容最大宽度约 1024px，顶部问候/状态工具、红色 AI 问诊 CTA、2×2 健康指标网格。
- 右侧 360px 信息栏，个人资料、用药提醒和近期报告。
- 使用本地男性头像和 Apple Watch 图片；不新增替代性插画。
- 保留 AI 问诊 CTA 和导航切换交互。

## 健康趋势结构

- 顶部横向导航包含品牌、仪表盘/趋势/病历/用药导航、搜索、通知、设置和头像。
- 主内容顶部为标题、说明和时间范围切换。
- 主区域使用 12 栏：趋势图 8 栏，患者资料与近期记录 4 栏。
- 趋势图下方为三张指标卡，右栏包含患者资料和四条近期记录。
- 底部使用原型页脚，不显示应用左侧栏。
- 趋势范围和指标选择保留交互状态。

## 组件边界

- `App.jsx` 根据页面 ID 选择页面专属壳层：首页和健康趋势直接渲染；其余三个页面继续使用现有 `AppShell`。
- 首页新增专属 `HomeSidebar` 和 `HomeRightRail` 结构，但复用现有导航数据和路由函数。
- 健康趋势新增专属 `TrendsTopNav` 和 `TrendsFooter`。
- 两页使用独立 CSS 命名空间，避免修改病历、问诊和用药页面样式。

## 响应式

- 桌面验收以 Stitch 原始视口为主。
- 低于 1024px 时首页侧栏折叠、右栏移至主内容下方；健康趋势顶部导航改为可收起菜单。
- 390×844 下保持无水平滚动和核心 CTA 可操作。

## 验收标准

- 首页和健康趋势在原始 Stitch 视口截图中，页面壳层和主要区块比例一致。
- 首页不再出现通用顶部工具栏，健康趋势不再出现左侧栏。
- 两页所有可见图片来自本地 Stitch 资源。
- SPA hash 导航、首页 AI 问诊 CTA、趋势时间范围和指标选择正常。
- 其余三个页面视觉结构和交互不受影响。
- `npm test` 与 `npm run build` 通过，浏览器控制台无错误。
