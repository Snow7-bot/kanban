# 健康趋势左侧导航统一设计

## 目标

将健康趋势页面当前的独立顶部导航替换为病历记录、AI 问诊和用药管理正在使用的共享左侧导航栏。健康趋势页不显示顶部工具栏，主体趋势内容和页脚保持现状。

## 页面外壳

- 健康趋势页通过现有 `AppShell` 渲染，并复用现有 `Sidebar` 组件。
- `AppShell` 增加一个最小的顶部工具栏显示开关；健康趋势页关闭顶部工具栏，其余共享外壳页面保持原行为。
- 健康趋势路由使用共享应用外壳，不再使用独立的 `trends` 页面外壳模式。
- 健康趋势导航项沿用 `Sidebar` 的选中状态、图标、字体、颜色、间距和交互。

## 导航尺寸与响应式

- 桌面端左侧导航宽度沿用共享变量 `--sidebar-width: 224px`。
- 共享断点下继续沿用现有 `198px` 导航宽度。
- 移动端沿用共享侧栏抽屉行为。
- 因健康趋势页不显示顶部工具栏，移动端提供一个独立的菜单按钮用于打开侧栏；该按钮不构成顶部工具栏。

## 健康趋势内容

- 删除健康趋势页内的 `TrendsTopbar` 结构及其菜单状态。
- 保留健康趋势标题、指标切换、趋势图、三张统计卡、患者资料、近期记录和页脚。
- 内容宽度改为适应共享 `page-canvas` 的可用空间，避免左侧导航出现后产生横向溢出。
- 不修改病历记录、AI 问诊、用药管理和首页的结构或视觉样式。

## 交互

- 左侧导航所有项目继续通过现有 hash 路由切换页面。
- 健康趋势导航项显示当前页选中状态。
- 健康趋势指标切换继续保留现有交互。
- 移动端点击菜单按钮打开左侧导航，完成导航后自动关闭。

## 测试与验收

- 先更新外壳契约测试，证明健康趋势必须进入共享应用外壳。
- 增加结构测试，证明健康趋势不再包含顶部导航，同时仍保留主要趋势内容和页脚。
- 验证病历记录、AI 问诊和用药管理仍显示原顶部工具栏。
- 浏览器桌面验收：健康趋势左侧导航与其他共享页面完全复用同一组件，且没有顶部工具栏。
- 浏览器移动端验收：无横向溢出，独立菜单按钮可打开和关闭侧栏。
- 运行完整 `npm test` 和 `npm run build`，并检查浏览器控制台无错误。
