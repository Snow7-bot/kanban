# 康伴智能医疗助手 — 前后端联调说明

## 1. 项目与启动

| 模块 | 路径 | 启动命令 |
| --- | --- | --- |
| 前端 | `kangban-web` | `npm run dev -- --host 127.0.0.1` |
| 后端 | `kangban-server` | `mvn spring-boot:run -Dspring-boot.run.profiles=dev` |

前端本地环境变量：

```env
VITE_API_BASE_URL=http://localhost:8080
VITE_API_TIMEOUT=15000
VITE_UPLOAD_MAX_SIZE=10485760
```

后端 Controller 没有 `/api` 前缀。前端请求必须从 `http://localhost:8080` 直连，例如 `POST /auth/login`、`GET /health/trends`。

本地运行依赖 MySQL、Redis 和 MinIO；真实的数据库、缓存、对象存储和 JWT 配置只通过本机环境配置提供，不写入本文档。

## 2. 服务地址

- Swagger UI（浏览、调试接口）：`http://localhost:8080/swagger-ui/index.html`
- OpenAPI JSON（供程序读取；直接打开会显示原始 JSON）：`http://localhost:8080/api-docs`
- 前端开发预览：`http://127.0.0.1:5173`

## 3. 数据库迁移

| 迁移 | 用途 |
| --- | --- |
| `V1__init_schema.sql` | 创建核心业务表 |
| `V2__seed_data.sql` | 保留历史迁移一致性；不再插入演示账号或示例数据 |
| `V3__add_refresh_token_revoked.sql` | 为刷新令牌增加撤销标记 |

本地测试请通过注册接口创建账号，不依赖固定演示账号。

## 4. 已对齐的核心契约

### 健康指标

`POST /health/records`

```json
{
  "memberName": "自己",
  "metric": "heart_rate",
  "value": "72",
  "unit": "bpm",
  "recordedDate": "2026-07-22",
  "recordedTime": "08:00",
  "note": "晨起测量"
}
```

可用 `metric`：`blood_pressure`、`blood_sugar`、`heart_rate`、`temperature`、`weight`。趋势查询使用相同编码：`GET /health/trends?metric=heart_rate&member=自己&days=30`。

### 用药管理

`POST /medications`

```json
{
  "name": "示例药品",
  "dosage": "1",
  "unit": "片",
  "instruction": "饭后服用",
  "frequency": "每天",
  "inventory": 30,
  "times": "08:00,20:00"
}
```

用药列表响应是分页对象，前端使用其 `list` 字段。用药历史接口必须携带药品 ID：`GET /medications/history?medicationId={id}`。

### AI 问诊

`POST /consultation/sessions`

```json
{
  "title": "在线问诊 - 2026/7/22",
  "patientData": "{\"name\":\"用户\",\"age\":39,\"gender\":\"男\"}"
}
```

`title` 必填；`patientData` 是序列化后的 JSON 字符串。消息接口为 `POST /consultation/sessions/{id}/messages`，请求体为 `{ "content": "..." }`。

### 病历详情

`GET /medical-records/{id}` 返回的关键字段：

- 基础信息：`recordName`、`recordType`、`recordDate`、`hospital`、`department`、`doctor`
- 文件：`fileUrl`
- 解析结果：`confidence`、`diagnosisData`、`medicationsData`、`advicesData`

后三个解析字段是 JSON 字符串。前端必须安全解析；为空或格式无效时展示“暂无解析结果”，不得用固定医院、医生或诊断演示文案替代。

## 5. 当前边界

- 验证码、OCR、AI 问诊回复和药物相互作用仍为开发阶段模拟能力。
- 上传仅允许 PDF、JPG、PNG，最大 10MB。
- AI 输出仅作健康参考，不替代医生诊断或处方。

## 6. 验证命令

```bash
cd kangban-web
npm test
npm run build

cd ../kangban-server
mvn -o test -q
mvn -o package -DskipTests -q
```
