# 康伴 Agent 医疗安全策略

第七个优化任务已在现有问诊链路中增加确定性安全兜底，OCR 不在本任务范围内。

## 已执行的安全边界

- 疑似胸痛、呼吸困难、意识异常、单侧无力、大出血或自伤风险时，服务端直接返回急症分流提示，
  不等待模型，也不继续执行 RAG 或患者工具调用。
- 模型提示词明确禁止确诊、处方、具体剂量调整、停药和换药指令。
- 若模型仍输出明确诊断或处方式指令，服务端替换为专业就医提示。
- RAG 启用时，回答只能使用本轮后端提供的真实资料和结构化引用；无证据时沿用拒答策略。
- RAG 未提供资料时，模型不得声称答案来自指南、数据库或某份资料。
- 前端问诊区持续显示授权患者范围、引用边界和急症就医提示。
- 交互工具仍为只读；任何未来写操作必须走“草案—用户确认—服务端校验—写入—审计”。

## 重要说明

这些规则用于 Demo 和上线前安全门禁，不能替代医疗机构的临床审核、人工转诊、合规评估和正式
医疗器械/互联网医疗要求。生产环境仍应配置人工客服或医生转诊通道，并对安全规则建立版本化
评测集和误报/漏报复盘机制。
