# 康伴发布候选版本检查与回滚手册

## 1. 当前发布范围

本候选版本包含登录、个人资料、家庭成员与授权共享、健康指标、病历管理、PDF 导出、用药管理和 AI 问诊前后端闭环。

暂不作为上线验收项：

- OCR 真实识别质量；
- 受本机代理网络影响的 AI 供应商连通性；
- 自助找回密码。当前由管理员 `13602060910` 核验账号后协助处理。

## 2. 环境与密钥

后端生产变量参考 `kangban-server/.env.production.example`，前端构建变量参考 `kangban-web/.env.production.example`。

- 所有真实密码、JWT 密钥和 API Key 仅保存在部署平台的 Secret 或宿主机受限环境文件中；
- 不向前端注入任何数据库、Redis、MinIO、JWT 或 AI 密钥；
- `APP_BASE_URL` 为用户访问前端的 HTTPS 地址；
- `APP_CORS_ALLOWED_ORIGINS` 只包含明确允许的 HTTPS 前端域名；
- 生产环境必须使用 `SPRING_PROFILES_ACTIVE=prod`，该 Profile 默认关闭 Swagger。
- `KANGBAN_CAPTCHA_SECRET` 使用独立随机值，不能与 JWT 或数据库密码复用。

## 3. 发布前检查

在仓库根目录执行：

```bash
bash scripts/release-check.sh
```

通过标准：

- 工作区无空白错误；
- 当前版本和 Git 历史未命中常见真实密钥格式；
- 前端测试与生产构建通过；
- 后端测试与 JAR 打包通过。

数据库使用独立验证库从空库执行全部 Flyway 迁移。不得清理或复用开发库。

本次本地验证记录（2026-07-30）：

- 独立验证库：`kangban_verify_rc_20260730`；
- Flyway V1–V10 全部成功，最终版本为 V10；
- 验证库共创建 20 张业务及迁移表，6 张关键新增表全部存在；
- `prod` Profile 可启动，`/actuator/health` 返回 `UP`，生产 Swagger 已关闭；

## 4. 部署顺序

1. 备份生产 MySQL，并确认备份可恢复。
2. 备份 MinIO 对象存储或启用对象版本控制。
3. 保存当前前端静态包和后端 JAR 的版本号及校验值。
4. 使用生产变量构建 `kangban-web/dist`，发布到 HTTPS 静态站点。
5. 发布 `kangban-server/target/kangban-server-1.0.0.jar`。
6. 启动后端，由 Flyway 自动执行尚未应用的迁移。
7. 检查 `/actuator/health` 返回 `UP`，再切换入口流量。

## 5. 上线验收

- 访客首页可访问，受保护功能弹出登录提示；
- 用户名注册、本地图片人机验证、登录、刷新令牌和退出登录正常；
- 忘记密码页面只展示管理员联系方式，不提供未验证手机号自助重置；
- 个人资料保存后首页、侧栏和头像立即同步；
- 家庭账号权限严格隔离，撤销后立即失效；
- 健康录入、趋势和周报数据一致；
- 用药新增、服药确认和相互作用提示正常；
- 病历详情、普通 PDF、含分析 PDF、分享创建与撤销正常；
- 日志中不出现密码、验证码、JWT、API Key 或完整手机号。

## 6. 回滚

应用回滚：

1. 停止新版本流量。
2. 恢复上一版本前端静态包。
3. 恢复上一版本后端 JAR 和对应环境配置。
4. 启动后端并检查健康状态，再恢复流量。

数据库回滚：

- Flyway 迁移文件只允许向前追加，禁止修改已经执行的版本；
- 如果新迁移只新增兼容字段或表，优先回滚应用而不回滚数据库；
- 如果迁移包含不兼容变更，停止写入后使用发布前备份恢复；
- 禁止通过删除 `flyway_schema_history` 或执行 `flyway repair` 代替数据恢复。

发布失败后应保留失败日志、版本号和迁移版本，但不得在报告中粘贴任何密钥。
